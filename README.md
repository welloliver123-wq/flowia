# Site FlowIA

Landing page da FlowIA: CRM com multiagentes de IA no WhatsApp e no Instagram.

## Estrutura

- `index.html`: o site inteiro em um único arquivo, com as imagens embutidas. Para publicar, basta subir este arquivo.
- `assets/`: arquivos originais dos logos (FlowIA e clientes), guardados como reserva.

## Como visualizar

Abra o `index.html` no navegador. Os vídeos do YouTube só tocam dentro da página quando o site está num servidor (por exemplo `python -m http.server`); aberto direto do computador, o clique leva para o YouTube.

## Pendências antes de publicar

- Aprovação dos depoimentos pelos clientes (Loja Viana, Recicle Express, Polipedras, Rachid Veículos).
- Manter no servidor as páginas `/conteudos/`, `/parceiros/`, `/para-atacado-e-distribuicao/` e `/privacidade/`, porque o site aponta para elas.
